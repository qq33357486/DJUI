# 进度条 Runtime 约定

## 结构

线性进度条由两个页面节点组成：

- 背景节点：`Panel`，使用 `通用长槽底框.png`
- 进度节点：`Progress`，使用 `进度条填充.png`

Runtime 会把线性 `Progress` 渲染为“圆角裁剪容器 + 完整进度图”。进度值改变裁剪区域，不把进度图直接压缩成当前百分比，因此 1% 和 5% 仍保持圆头。

## 横向素材切片

当前横向长槽只配置左右切片，上下保持 0：

```json
{
  "background": [53, 0, 32, 0],
  "fill": [29, 0, 28, 0]
}
```

四个值依次为 `[left, top, right, bottom]`。左右切片保护两端圆头，中间区域横向拉伸；上下不锁定，避免当前控件高度下上下边缘变薄。

切片配置的唯一来源是工作区 `.djui/slice-meta.json`，不要只在页面 JSON 中手写。发布器会根据素材路径注入切片数据，并清理已经取消的旧配置。

## 模式

- `LeftToRight`、`RightToLeft`、`TopToBottom`、`BottomToTop` 使用 DJUI 自定义线性渲染。
- `Clockwise`、`CounterClockwise` 保留星火引擎原生环形 `Progress` 渲染。

## 验收

验收至少检查 0%、1%、5%、50%、100%，以及四个线性方向。重点确认：

1. 1% 不出现方形起点；
2. 进度图与背景图没有重复套框；
3. 50% 中间区域自然拉伸；
4. 100% 两端圆头完整；
5. 正式页面和验收页都使用相同的左右切片配置。

# 安全说明

DJUI 是纯前端应用：没有后端服务，所有文件读写通过浏览器 File System Access API 完成，目录访问权限由用户在浏览器中显式授权。安全边界是「浏览器授权了哪些目录，编辑器就能读写哪些目录」。

## 文件访问模型

- 工程/UI 工作区目录通过 `showDirectoryPicker` 由用户主动选择并授权，浏览器记住授权。
- 最近工程列表保存在浏览器 localStorage，不落任何本机配置文件。
- 编辑器只对用户授权的目录做读写；没有授权就没有任何文件访问能力。
- 发布、Runtime 安装等写操作的目标目录都来自用户显式选择的工程配置。

## 部署形态

- 本地开发：`npm run dev`（仅 Vite dev server）。
- 生产部署：`npm run build` 产物为纯静态文件，Docker 镜像是 Nginx 静态托管，不含任何服务端逻辑、环境变量或机密。
- 构建产物内联的 `?raw` 内容（Runtime 源码、CHANGELOG 等）全部来自仓库本身，不含本机路径或凭据。

## 仓库卫生

公开提交前请确认没有把以下内容提交到仓库：

- `.env`
- `node_modules/`
- `dist/`
- UI 工作区中的临时素材、原始大图和私有资源

## 发现安全问题

如果发现绕过目录授权读写文件、构建产物泄漏机密等问题，请优先通过 GitHub Security Advisory 或私下渠道告知维护者。公开 issue 中不要贴真实敏感路径或复现所需的私有文件内容。
